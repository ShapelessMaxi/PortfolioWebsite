	TouchDesigner Prototype 01 - November 2024
Scratch this pile of operators, I need a script that will do all the simple operations of this colorAnalyzeTOPs in a for loop. Also, there's probably a way to create operators and so I'll be able to change, modify, expand it easily ans faster.
I'm starting to work with NumPy because basically, you can read an image as a really long 2D array populated by every pixel of the image. The pixels are an object. There's useful methods like split(), making it possible to digest the array by smaller areas, and variables, like the .r, .g and .b values of each pixels. In brief, the NumPy array and split into cells[x,y]. The RGB values of each pixels of each cells are averaged, basically smudging them all together. I export both an image, and a table containing all colors in written form (this was more for debugging purposes). Then, to create the visual, I am storing a 3Dspheres node system in a baseComp, and copying it a bunch as much times as the image is split. The colors of each sphere changes according to what's in front of the camera, and to what colors are in the reference Table. They get smaller if the input's color is not registered. This process is dynamic and live and not slow!

In this prototype, I'm doing a few very sensible things
- storing a dynamic reference color table 
- storing x and y size of the split/grid
